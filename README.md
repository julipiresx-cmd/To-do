# To-Do List

## 📋 Sobre o projeto

O To-Do List é um sistema desenvolvido para ajudar o usuário a organizar e acompanhar suas tarefas do dia a dia de forma simples e prática.

O sistema permite que o usuário cadastre, visualize, edite, conclua e exclua tarefas.

## 🎯 Objetivo

O objetivo do projeto é criar um site que trabalha com listas, planilhas e tarefas, fácil de usar, com um formatos mais redondos, colorido com cores pastéis, que seja fácil de salvar e deletar.

## ⚙️ Funcionalidades

- Criar tarefas
- Visualizar tarefas
- Editar tarefas
- Concluir tarefas
- Excluir tarefas

## 👤 Usuário

O sistema possui um único ator principal:

**Usuário:** responsável por criar, visualizar, editar, concluir e excluir suas tarefas.

## 🖥️ Como utilizar

1. Acesse o sistema.
2. Crie uma nova tarefa.
3. Visualize as tarefas cadastradas.
4. Edite uma tarefa quando necessário.
5. Marque uma tarefa como concluída após realizá-la.
6. Exclua tarefas que não sejam mais necessárias.

## 📌 Requisitos do sistema

O sistema deve permitir que o usuário:

- Cadastre novas tarefas;
- Consulte as tarefas cadastradas;
- Altere informações de uma tarefa;
- Marque tarefas como concluídas;
- Remova tarefas da lista.
